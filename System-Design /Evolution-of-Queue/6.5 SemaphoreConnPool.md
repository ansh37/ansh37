# Stage 6.5: The Resource Manager (Semaphore Connection Pool)

## Overview
While Mutexes and Condition Variables can build a Connection Pool, the fundamentally correct concurrency primitive for managing a fixed pool of identical resources is a **Counting Semaphore**.

A Semaphore maintains an internal counter. 
* `acquire()` decrements the counter. If it reaches 0, the thread blocks.
* `release()` increments the counter and wakes up a blocked thread.

## Key Engineering Concepts
1. **The Semaphore + Mutex Duo:** A Semaphore controls *how many* threads can access the resource pool, but it does not protect the data structure itself. You must still use a Mutex to protect the internal queue (`std::queue` or `collections.deque`) during the actual push/pop operations.
2. **C++20 `<semaphore>`:** Native semaphores were introduced in C++20. We use `std::counting_semaphore`.
3. **Timeouts (`try_acquire_for`):** To maintain the load-shedding architecture from Stage 3.5, we do not block indefinitely. We use timed semaphore acquisitions.

## Implementation: C++20

```cpp
#include <queue>
#include <mutex>
#include <semaphore> // Requires C++20
#include <memory>
#include <chrono>
#include <iostream>
#include <atomic>

class DBConnection {
public:
    int id;
    bool is_connected = true;
    explicit DBConnection(int i) : id(i) {}
    bool ping() const { return is_connected; }
    void executeQuery(const std::string& query) { std::cout << "Conn " << id << " executing.\n"; }
};

// We define the maximum possible connections at compile time for the semaphore
constexpr ptrdiff_t MAX_POOL_SIZE = 100;

class SemaphoreConnectionPool {
private:
    std::queue<std::unique_ptr<DBConnection>> pool;
    std::mutex mtx; // Protects the queue
    std::counting_semaphore<MAX_POOL_SIZE> sem; // Controls access limits
    std::atomic<int> next_conn_id{0};

public:
    explicit SemaphoreConnectionPool(ptrdiff_t initial_size) : sem(initial_size) {
        for (ptrdiff_t i = 0; i < initial_size; ++i) {
            pool.push(std::make_unique<DBConnection>(next_conn_id++));
        }
    }

    struct PoolDeleter {
        SemaphoreConnectionPool* pool_ptr;
        void operator()(DBConnection* raw_conn) {
            pool_ptr->release(std::unique_ptr<DBConnection>(raw_conn));
        }
    };

    using SmartConnection = std::unique_ptr<DBConnection, PoolDeleter>;

    // ==========================================
    // Core Acquire (Semaphore Wait)
    // ==========================================
    SmartConnection acquire(std::chrono::milliseconds timeout = std::chrono::milliseconds(500)) {
        // 1. Wait on the Semaphore (Blocks until a token is available or timeout hits)
        if (!sem.try_acquire_for(timeout)) {
            throw std::runtime_error("Connection Pool Timeout: No available connections.");
        }

        std::unique_ptr<DBConnection> conn;

        // 2. Safely extract from the queue (Requires Mutex because multiple threads 
        //    could have passed the semaphore simultaneously!)
        {
            std::lock_guard<std::mutex> lock(mtx);
            conn = std::move(pool.front());
            pool.pop();
        }

        // 3. Health Check (Done OUTSIDE the lock to avoid blocking other threads)
        if (!conn->ping()) {
            std::cout << "Connection " << conn->id << " died. Re-establishing...\n";
            conn = std::make_unique<DBConnection>(next_conn_id++);
        }

        return SmartConnection(conn.release(), PoolDeleter{this});
    }

    // ==========================================
    // Core Release (Semaphore Signal)
    // ==========================================
    void release(std::unique_ptr<DBConnection> conn) {
        // 1. Safely put the connection back in the queue
        {
            std::lock_guard<std::mutex> lock(mtx);
            pool.push(std::move(conn));
        }
        
        // 2. Signal the Semaphore to wake up exactly one waiting thread
        sem.release(); 
    }
};
```

## Python Code
```py
import threading
from collections import deque
from contextlib import contextmanager
from typing import Generator

class DBConnection:
    def __init__(self, conn_id: int):
        self.conn_id = conn_id
        self.is_connected = True
        
    def ping(self) -> bool:
        return self.is_connected

class SemaphoreConnectionPool:
    def __init__(self, size: int):
        self._pool: deque[DBConnection] = deque()
        self._lock = threading.Lock() # Protects the deque
        self._semaphore = threading.Semaphore(size) # Controls availability
        self._next_conn_id = 0
        
        for _ in range(size):
            self._pool.append(self._create_new_connection())

    def _create_new_connection(self) -> DBConnection:
        conn = DBConnection(self._next_conn_id)
        self._next_conn_id += 1
        return conn

    def _raw_acquire(self, timeout_seconds: float) -> DBConnection:
        # 1. Acquire Semaphore Token
        if not self._semaphore.acquire(timeout=timeout_seconds):
            raise TimeoutError("Connection Pool Timeout: No available connections.")
            
        # 2. Extract from Deque safely
        with self._lock:
            conn = self._pool.popleft()
            
        # 3. Health check outside the lock
        if not conn.ping():
            conn = self._create_new_connection()
            
        return conn

    def _raw_release(self, conn: DBConnection):
        # 1. Put back into Deque safely
        with self._lock:
            self._pool.append(conn)
            
        # 2. Release Semaphore Token
        self._semaphore.release()

    @contextmanager
    def acquire(self, timeout_seconds: float = 0.5) -> Generator[DBConnection, None, None]:
        """RAII / Context Manager Wrapper over the raw acquire/release APIs"""
        conn = None
        try:
            conn = self._raw_acquire(timeout_seconds)
            yield conn
        finally:
            if conn is not None:
                self._raw_release(conn)
```
